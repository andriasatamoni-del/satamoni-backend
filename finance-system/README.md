# نظام الحسابات والإدارة المالية المتكامل لمطاعم ستاموني

**Satamoni_Financial_Management_System** — نظام قيد مزدوج كامل على Google Sheets (يعمل أيضًا في Excel)، مبني بمعادلات حقيقية مترابطة، لثلاثة فروع (ويقبل المزيد) ومخزن رئيسي وسنتر كيتشن وإدارة.

> **الحالة: المرحلة 1 مكتملة ومختبرة** (دليل الحسابات، الإعدادات، الخزائن، المبيعات والمنصات، المصروفات، الموردون، اليومية، الأستاذ، ميزان المراجعة، قائمة الدخل، الميزانية، التدفقات، الإقفال، لوحة التحكم). هياكل المراحل 2–4 (مشتريات تفصيلية، مخزون، سنتر كيتشن، رواتب، أصول) جاهزة في الملف وغير مفعّلة بعد.
>
> **تنبيه مهم:** النظام غير معتمد قانونيًا أو ضريبيًا؛ راجع محاسبًا قانونيًا مصريًا قبل الاعتماد. كل الأرقام في الملف التجريبي **تجريبية** وليست بيانات المطعم.

## كيف تفتح الملف في Google Sheets

لا يمكن إنشاء ملف Google Sheets مباشرة من بيئة التطوير هذه، لذا سُلِّم ملف Excel متوافق:

1. افتح Google Drive ← **جديد ← رفع ملف** ← اختر `Satamoni_Financial_Management_System.xlsx` (أو النسخة النظيفة).
2. انقر عليه بالزر الأيمن ← **فتح بواسطة ← Google Sheets** ثم **ملف ← حفظ كـ Google Sheets** (احفظ الاسم `Satamoni_Financial_Management_System`).
3. اضبط **ملف ← الإعدادات**: المنطقة الزمنية `(GMT+02:00) Cairo` واللغة/الإقليم `مصر`.
4. انتظر اكتمال الحساب (الملف يحوي نحو 350 ألف معادلة؛ قد يستغرق التحميل الأول دقيقة).
5. افتح ورقة `Test_Cases`: يجب أن تظهر كل الاختبارات الحية (نجح). أبلغ عن أي (فشل) — الاختبار الأساسي لتوافق Google Sheets (لم يُختبر داخله من هنا، اختُبر بـ LibreOffice؛ انظر المشكلات المعروفة).
6. للنسخة النظيفة: أدخل بياناتك الأساسية (Locations, Treasuries, Suppliers, Users…) ثم القيد الافتتاحي في `Manual_JE`، وغيّر `Settings!S_Mode` إلى (تشغيلي).

## البدء السريع (5 دقائق)

1. `Dashboard`: لمحة سريعة وتنبيهات. 2. `Guide` و`User_Manual`: دليل الأوراق والتشغيل. 3. `Settings`: فترة التقارير. 4. أدخل المستندات في أوراقها (الخلايا الصفراء فقط). 5. غيّر الحالة: مسودة ← معتمد (المعتمد) ← مرحل (المحاسب) فتظهر النتائج في `GL_Journal` والتقارير. 6. `Close_Checklist` ثم `Period_Close` للإقفال.

## إعادة بناء الملفات (اختياري)

```bash
pip install openpyxl
cd build
python3 build_system.py --out ../output --scale 1.0     # scale>1 لسعة صفوف أكبر
python3 forms.py ../forms                               # النماذج
python3 build_docs.py x                                 # التوثيق
python3 pipeline.py --out ../output --work /tmp/work    # بناء + إعادة حساب LibreOffice + اختبارات
```

## قواعد النظام الأساسية (مختصر)

قيد مزدوج ومتوازن دائمًا؛ فصل النقدية عن المبيعات والربح والمخزون؛ الشراء مخزون وليس مصروفًا؛ التحويلات الداخلية (نقدية/مخزون) لا تمس الإيراد أو المصروف أو التكلفة؛ لا حذف ولا تعديل بعد الترحيل (عكس وتصحيح موثق)؛ المُعِد ≠ المعتمد ≠ المرحِّل؛ سجل مركزي لأرقام المستندات يمنع التكرار؛ لا يُخفي النظام الأخطاء بصفر بل يظهرها في عمود الفحص وقائمة الإقفال؛ لا تُعرض النتائج كنهائية إذا وُجدت بنود إقفال حرجة مفتوحة.
