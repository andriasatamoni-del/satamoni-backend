# مرجع الأوراق والأعمدة والمعادلات

لكل ورقة: وظيفتها، أعمدتها (إدخال يدوي أم معادلة)، قواعد التحقق، وعيّنة من الصيغة الفعلية في أول صف. الصيغ تستخدم نطاقات أعمدة كاملة (`Sheet!$A:$A`) ولا تعتمد على أرقام صفوف ثابتة للتقارير؛ وصفوف المستندات تحتوي صيغًا لعدد صفوف محدد مسبقًا (انظر المشكلات المعروفة: سعة الصيغ).

**الصفوف الجديدة:** أضف المستند في أول صف فارغ داخل نطاق التنسيق (الخلايا الصفراء). المعادلات (الرمادية) موجودة مسبقًا ومحمية. عند امتلاء الصفوف انسخ آخر صف معادلات لأسفل (بعد إلغاء الحماية) أو ابنِ ملفًا جديدًا بسعة أكبر.
