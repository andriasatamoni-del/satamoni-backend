# تثبيت وتشغيل Apps Script (اختياري)

النظام يعمل بالكامل بالمعادلات دون أي سكربت. السكربت يضيف: سجل مراجعة آلي، حماية الصيغ والصفوف المرحلة، إقفال بلقطة قيم، نسخة احتياطية.

## التثبيت
1. افتح ملف Google Sheets ← **الإضافات (Extensions) ← Apps Script**.
2. احذف الكود الافتراضي والصق محتوى `apps_script/Code.gs` كاملًا، ثم **احفظ** (Ctrl+S).
3. أعد تحميل الملف؛ سيظهر قائمة **ستاموني** في الشريط العلوي.
4. اختر ستاموني ← **1) تفعيل سجل المراجعة**؛ ستظهر نافذة تفويض (Authorization): اختر حسابك ← متقدم ← السماح.
5. **قبل** تطبيق الحماية: أدخل بريد كل مستخدم في ورقة `Users` (عمود بريد جوجل) مع دوره.
6. ستاموني ← **2) تطبيق حماية الصيغ والصفوف المرحلة**.
7. كرّر الخطوة 2 بعد كل دفعة ترحيل (أو أنشئ مشغّلًا زمنيًا يوميًا للدالة `lockPostedRows`).

## الصلاحيات (Scopes) المطلوبة
| الصلاحية | سببها |
|---|---|
| عرض وتعديل جداول البيانات (spreadsheets) | تسجيل Audit_Log، قراءة الأسماء المعرّفة، كتابة لقطة الإقفال |
| إنشاء المشغّلات (script.scriptapp) | مشغّل onEdit القابل للتثبيت |
| Drive (drive) | نسخة احتياطية (makeCopy) |
| بريد المستخدم (userinfo.email) | تسجيل اسم من قام بالتعديل والتحقق من الصلاحية |
| واجهة المستخدم (script.container.ui) | القائمة والتنبيهات |

## ما يفعله كل أمر
- **تفعيل سجل المراجعة:** يسجل كل تعديل في الأوراق المصدرية والبيانات الأساسية (التاريخ، الورقة، الخلية، القيمة القديمة والجديدة، بريد المنفذ). يمنع (يتراجع عن) تعديل أي خلية في صف حالته (مرحل) لغير المدير المالي/الإدارة العليا ويسجل المحاولة.
- **تطبيق الحماية:** يحمي كل ورقة ويترك خلايا الإدخال (رؤوسها زرقاء) قابلة للتعديل للمحررين المحددين حسب الدور، ثم يقفل الصفوف المرحلة.
- **فحص جاهزية الإقفال:** يعرض عدد البنود الحرجة وبنود المراجعة من Close_Checklist.
- **إقفال الفترة:** يرفض عند وجود بنود حرجة أو فترة غير شهر كامل أو مستخدم غير مخوّل؛ وإلا يكتب لقطة (الإيرادات، الربح، إجمالي المدين والدائن) ويضع الحالة (مقفلة) وتاريخ الإقفال.
- **نسخة احتياطية:** نسخة كاملة بتاريخ ووقت (ضع معرّف المجلد في `BACKUP_FOLDER_ID` لحفظها في مجلد).

## تنبيهات
- مالك الملف يستطيع إيقاف السكربت والحمايات؛ هذه ضوابط وقائية لا أمنية مطلقة.
- لا يعتمد أي جزء من حسابات النظام على السكربت: لو حُذف يبقى كل شيء يعمل ويبقى الملف سليمًا.
- بعد تطبيق الحماية: لإضافة صفوف/أعمدة أو تغيير صيغة، افتح البيانات ← حماية الأوراق والنطاقات وعدّل مؤقتًا كمالك.
