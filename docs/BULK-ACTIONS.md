# إجراءات جماعية (Bulk Actions)

المرحلة 7R بتضيف إجراءات جماعية في 3 شاشات - كانت النقطة دي من قايمة "لو عايزين" في تدقيق المرحلة
7D. الثلاث إضافات بتستخدم نفس الـendpoint المفرد الموجود أصلًا، مرة لكل عنصر متحدد - مفيش endpoint
جماعي جديد في الباك إند ولا migration، عشان الفعل الفعلي (تفعيل/تعطيل صنف، تسجيل هالك) مختبر ومضمون
أصلًا على مستوى العنصر الواحد.

## 1. المنيو - تفعيل/تعطيل جماعي (`satamoni-menu.html`)

مفيد وقت نقص مكوّن مشترك بين أصناف كتير (مثلًا الجبنة خلصت وعندك 5 أصناف بيتزا بيها) - بدل ما كل صنف
يتعطّل لوحده. checkbox بجانب كل صنف + "تحديد الكل" + زرارين "تفعيل المحدد"/"تعطيل المحدد" بيلفوا على
الأصناف المحددة وينادوا `PATCH /api/menu/items/:id {isActive}` لكل واحد.

## 2. تسجيل هالك جماعي (`satamoni-kitchen.html`)

لحادثة واحدة أثرت على أكتر من صنف (انقطاع كهرباء، تلف تخزين، حريق صغير...) - جدول بكل الأصناف، كل
صف فيه checkbox + خانة كمية خاصة بيه، وسبب/تاريخ مشتركين لكل الأصناف المحددة. بيستخدم نفس
`POST /api/inventory/waste` الموجود أصلًا لكل صنف، وبيوري تقرير واضح لو صنف فشل (زي نقص رصيد) من غير
ما يوقف باقي الأصناف.

## 3. الموارد البشرية - تفعيل/تعطيل جماعي (`satamoni-payroll.html`)

مفيد وقت إجازة موسمية أو إنهاء تعاقد دفعة موظفين مع بعض. نفس نمط المنيو بالظبط - checkbox لكل موظف +
"تحديد الكل" + زرارين، بينادوا `PATCH /api/payroll/employees/:id {isActive}` لكل موظف محدد.

## ملاحظة تصميمية

الثلاث حالات بتنفّذ الطلبات **بالتتابع** (مش متوازي) وبتكمل حتى لو عنصر معيّن فشل - العداد النهائي
("اتفعّل X من Y") بيوضّح النتيجة الفعلية. ده قرار متعمّد: فشل جزئي (زي عنصر بصلاحية مرفوضة أو مخزون
غير كافي) لازم يبان بوضوح للمستخدم، مش يوقف كل العملية أو يتبلع بصمت.

## الملفات المتأثرة

- `public/satamoni-menu.html`
- `public/satamoni-kitchen.html`
- `public/satamoni-payroll.html`

مفيش تعديل باك إند أو schema - الثلاثة بيستخدموا endpoints مفردة موجودة أصلًا.

## اختبار

مفيش تعديل باك إند، فالفل ريجريشن (499/499) فضل زي ما هو. تحقق حقيقي بمتصفح (Playwright): تفعيل/تعطيل
جماعي لصنف منيو واحد (تأكيد الحالة اتقلبت والعداد صح)، تسجيل هالك جماعي لصنف بكمية محددة (تأكيد رسالة
النجاح)، وتفعيل/تعطيل جماعي لموظف واحد (تأكيد الحالة اتقلبت والعداد صح) - الثلاثة اتأكد منهم شغالين.
