# قالب سجل حوادث الطيار (Pilot Incident Log Template)

انسخ القالب ده لكل حالة أثناء الطيار المُتحكَّم فيه، مهما بدت صغيرة. الهدف: سجل واحد قابل للمراجعة بعد
الطيار، مش اعتماد على الذاكرة. راجع `docs/INCIDENT-RESPONSE.md` للتعامل التشغيلي الفوري مع الأعطال
الشائعة - القالب ده للتوثيق بعد/أثناء التعامل، مش بديل عنه.

### التصنيف - اختر واحد بالظبط

- [ ] **SOFTWARE BUG** - سلوك النظام نفسه غلط فعليًا (مش المستخدم اللي غلط)
- [ ] **DATA / CONFIGURATION** - بيانات أساسية غلط (سعر، صنف، إعداد فرع) مش كود
- [ ] **TRAINING** - الموظف مكنش عارف يستخدم الميزة الصحيحة
- [ ] **SOP** - الإجراء نفسه ناقص أو مش واضح
- [ ] **USER ERROR** - خطأ بشري بسيط (كتابة غلط، ضغط زرار غلط) - مش عيب نظام
- [ ] **EXTERNAL SYSTEM** - طلبات/إنترنت/طابعة/جهاز خارج تحكم النظام

**ملحوظة**: لا تصنّف كل خطأ بشري كـ"SOFTWARE BUG" - ده بيشوّه صورة الطيار الحقيقية. لو مش متأكد،
اكتب وصف الحالة كاملة وسيب التصنيف النهائي لمراجعة يومية/أسبوعية بدل تخمين فوري.

### القرار

- **حالة معزولة، مش هتتكرر**: وثّقها وسيبها - مش كل حادثة محتاجة إجراء.
- **نمط متكرر**: هل السبب SOP ناقص (أضف/عدّل SOP) ولا فعليًا bug (بلّغ المطوّر بتفاصيل الجدول فوق كاملة)؟
